# CLSR offline strategy benchmark

Generated by `Tools/CLSR.Offline` (`dotnet run -c Release -- eval`). Agents see only the
player-visible `PublicView` and submit plans through the game's own validation.
Variant 0 is each authored scenario; variants 1–100 keep the map, thresholds, caches,
reports and each branch's true total but re-place that branch's survivors at random.
`random` is repeated 20× per variant. The oracle is the exact optimum with full
knowledge of the hidden map — a ceiling no player can be expected to reach.

| Agent | Strategy |
| --- | --- |
| `random` | Uniformly random legal plan (including sending nobody). |
| `greedy-rescue` | Maximises today's expected rescues from branch reports and revealed counts (unknown crossings estimated at one point on cumulative maps); ties use fewer points. |
| `explorer` | Maximises newly revealed thresholds and counts per day; rescues only break ties. |
| `cache-aware` | Greedy rescue plus 0.5 survivor-equivalents per storage point while later days remain. |
| `risk-aware` | Today's mean rescues over sampled thresholds/placements, minus 0.5 per point lost on blocked teams. |
| `lookahead` | Monte-Carlo hindsight planner: mean over sampled worlds of today's rescues plus that world's optimal remaining days. |
